# R16 — 게임 시작 가능 조건 검증

## 범위

R16은 **시작 요청의 자격과 로비 상태를 검사만** 합니다. 게임 상태 변경, AI 물품 생성, 카드 배분, 세션 생성, 설정 스냅샷은 **G03 이후**에 구현합니다. R11/R12 정책대로 플레이어 **1~2명도 Ready 가능**하지만 게임 시작에는 정확히 3명이 필요합니다.

### 요구 조건 (검사 순서)

1. 방 코드가 존재하며 `RoomStatus.WAITING`일 것.
2. 요청 `playerId`가 그 방의 구성원일 것.
3. 요청자가 **Host**일 것. Host 권한은 `MODERATOR`/`GUEST` 로비 역할과 독립적입니다.
4. 참가자가 **정확히 3명**일 것.
5. 역할이 **`MODERATOR` 1명 + `GUEST` 2명**일 것 (`NONE` 불가).
6. **세 명 모두 `ready=true`**일 것.

같은 `Room` 행에 대한 `PESSIMISTIC_WRITE` 잠금 → 참가자 `FOR UPDATE` 조회 순서로 R05/R10/R11/R15와 일관성을 유지합니다. 검사는 DB를 변경하지 않으며, 진짜 게임 시작 트랜잭션(G03)에서 같은 트랜잭션 안에 재검증해야 검사/시작 사이의 경합을 방지할 수 있습니다.

## 임시 Swagger REST 검증 API

`POST /api/rooms/{roomCode}/start/check`

```json
{"playerId":"53"}
```

- `204 No Content`: 모든 시작 조건 충족. **실제 게임을 시작하지는 않음**.
- `403 NOT_HOST`: 같은 방의 비Host 요청.
- `404 ROOM_NOT_FOUND` / `PLAYER_NOT_IN_ROOM`: 방 없음 / 다른 방 플레이어 / 잘못된 ID.
- `409 ALREADY_STARTED`: 이미 WAITING 상태가 아님.
- `409 NOT_ENOUGH_PLAYERS`: 3명 미만.
- `409 INVALID_PLAYER_COUNT`: 3명 초과 (DB 이상 상태 방어).
- `409 INVALID_ROLE_COMPOSITION`: 사회자 1명·객원 2명 미충족.
- `409 NOT_ALL_READY`: 한 명이라도 준비 안 됨.

**기존 레거시 경로** `POST /api/game/{roomId}/start`는 Host 신원 확인 없이 바로 `IN_PROGRESS` 전환 및 더미 카드 생성이 가능했으므로 R16부터 `409 GAME_START_NOT_IMPLEMENTED`로 임시 차단했습니다. G03에서 실제 시작 API를 새 계약으로 확정해야 합니다.

## 프론트엔드/통신 참고

- 프론트엔드 `frontend/BACKEND_CONTRACT.md`는 현재 `SET_READY` 시 3명 미만 거부·전원 Ready 시 **자동 시작**하는 예전 목 서버 규칙을 담고 있습니다. **사용자가 확정한 최신 규칙**: 1~2명 Ready는 허용, 최종 시작은 Host 요청과 3명·역할·전원 Ready 검사 후 수행. 프론트 목 서버와 문서 동기화 필요.
- `SET_READY`는 Ready 상태 저장에만 사용하며 자동 시작하지 않습니다.
- 실제 WebSocket 이벤트 및 실제 시작 동작은 통신/G03 단계에서 구현합니다.
- Swagger REST 본문의 `playerId`는 신원 인증 수단이 아닙니다. 신원 검증과 Host ID 위조 방지는 배포 전 구현해야 합니다.
- 역할 선택 REST의 `roomCode`를 서비스에 전달하지 않는 기존 이슈는 **이번 변경에 포함하지 않았습니다**.

## 검증

1. `./gradlew clean test` 및 `./gradlew test --tests "*RoomServiceStartConditionsTest" --tests "*RoomControllerStartCheckTest" --tests "*GameControllerLegacyStartTest"`.
2. Host + 객원 2명 / 사회자 1명, 모두 Ready 시 204; GET 로비 조회에서 여전히 LOBBY 확인.
3. 2명 Ready → 409 `NOT_ENOUGH_PLAYERS` (Ready 등록 자체는 가능).
4. 역할 누락/중복 → 409 `INVALID_ROLE_COMPOSITION`.
5. 한 사람 Ready 취소 → 409 `NOT_ALL_READY`.
6. 비Host 시작 검사 → 403 `NOT_HOST`.
7. 다른 방 플레이어 ID → 404 `PLAYER_NOT_IN_ROOM`.
8. 구형 직접 시작 API → 409 `GAME_START_NOT_IMPLEMENTED`.
