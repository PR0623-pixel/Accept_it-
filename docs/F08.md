# F08: environment and error responses

## Configuration

Copy `.env.example` to `.env` and fill in local DB credentials. Never commit `.env`.
The template lists DB_NAME, DB_USER, DB_PASSWORD, DB_ROOT_PASSWORD,
OPENAI_API_KEY and OPENAI_MODEL. Password and API-key placeholders are empty.
Spring Boot reads process environment variables; it does not automatically load
this `.env` file. Export variables through the shell/IDE or explicitly pass them
through Docker Compose. DB_ROOT_PASSWORD is for MySQL initialization.

OpenAI defaults: an empty key and model `gpt-4o-mini`. The OpenAiService bean can
initialize without a key. AI calls with a missing/blank key or model fail with
503; database configuration is still required for a full application startup.

## API contract

Before: `{"errorMessage":"exception message"}` for IllegalArgumentException (400)
and IllegalStateException (409); other errors used framework defaults.
After: `{"code":"INVALID_ROOM_CODE","errorMessage":"존재하지 않는 방 코드입니다."}`.
The `errorMessage` field remains available to Unity. Generic argument/state
messages now use fixed public messages instead of exposing exception details.
Success responses are unchanged.

| HTTP | code | Trigger |
| --- | --- | --- |
| 400 | INVALID_ROOM_CODE | Unknown room code (original status retained) |
| 400 | BAD_REQUEST | Bad JSON, parameters, argument errors |
| 404 | NOT_FOUND | Missing route/resource |
| 405 | METHOD_NOT_ALLOWED | Unsupported HTTP method (Allow header retained) |
| 409 | ROOM_FULL | Room already has three players |
| 409 | CONFLICT | Other state conflicts |
| 415 | UNSUPPORTED_MEDIA_TYPE | Unsupported request content type |
| 500 | INTERNAL_SERVER_ERROR | Unexpected exception |
| 502 | AI_SERVICE_ERROR | AI transport/status error or invalid response envelope/content |
| 503 | AI_NOT_CONFIGURED | AI key/model missing or blank |

The advice replaces MVC framework error bodies with the common contract.
Fallback Spring Boot /error settings also suppress messages, stack traces,
exception types and binding details. No raw exception messages are returned.

## Verification and limits

Run `./gradlew.bat compileJava test --no-daemon` (Java 21).
Tests use standalone MockMvc and MockRestServiceServer without MySQL or external
OpenAI access. They cover HTTP error contracts, message redaction, malformed
requests, missing API key, bean initialization with an empty key, request fields,
valid AI responses, HTTP/network failures and malformed AI responses.

A full MySQL/Flyway-backed server startup and Unity integration have not been
executed. No live OpenAI request is performed. No secret file is read or staged.
